# What an evaluation claim publishes

A methods check, not a scorer. Take an existing evaluation and record which of these are actually present:

1. The case set was fixed, and its digest published, before the results.
2. The transcript covers that set. A missing case is not a pass.
3. Observation is separate from the judgment.
4. Attempted, observed, accepted, and effects verified are different fields. A refusal is not a skip. Not measured is not zero.
5. Benign cost is typed.
6. Repairs replay the earlier cases.

The first subject is the partial-compliance grid in agent-sec. The card should say which properties that study fails. AAIF Observability issue 66 is the public list this checks against. It is not an adopted standard.
